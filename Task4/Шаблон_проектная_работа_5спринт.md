| Роль  | Права роли | Группы пользователей |
| --- | --- | --- |
| cluster-admin | Полный доступ ко всем ресурсам кластера | DevOps-инженеры и администраторы инфраструктуры  |
| namespace-admin | Полный доступ к ресурсам в рамках конкретного namespace | DevOps инженеры |
| viewer | Только чтение всех ресурсов в кластере | Разработчики функциональных команд, бизнес-аналитики |

1. Выполнить скрипты в следующем порядке:
   ```bash
   minikube start
   
   ./create-roles.sh
   ./create-users.sh
   ./bind-users-to-roles.sh
   
   ```
