Требования:
|№|Категория|Требование|Комментарий|
| --- | ---------------------------------------------------------------------------------------------------------------------------------------- | -------| ------------ |
|1|Аутентификация|Все внешние интеграции должны использовать взаимную аутентификацию на основе сертификатов mTLS|Предотвращение атак типа "Man-in-the-Middle" и гарантия подлинности обеих сторон.|
|2|Авторизация|API партнёра должны проверять, что собственник имеет право управлять конкретным устройством|Устранение текущей проблемы PropDevelopment с API, где видны чужие данные |
|3|Аудируемость|Все действия по управлению устройствами (кто, когда, какое устройство, какая команда) должны логироваться с обеих сторон|Требуется для расследования инцидентов (например, если дверь открылась без разрешения).|

Протоколы аутентификации и авторизации:
|Взаимодействие|Протокол|Описание|
| -------------|--------| -------|
|Собственник -> Мобильное приложение|OAuth 2.0|Пользователь авторизуется в мобильном приложении. Приложение получает Access Token|
|Мобильное приложение -> smart-home-adapter|OAuth 2.0|Приложение передаёт Access Token пользователя в заголовке Authorization|
|smart-home-adapter -> Партнёр Умного дома|mTLS + OAuth 2.0|Адаптер аутентифицируется перед партнёром как доверенное приложение, а в теле запроса передаётся идентификатор пользователя|

Взаимодействие будет организовано следующим образом (далее один из возможных сценариев):
1. Пользователь нажимает кнопку "Открыть" в мобильном приложении.
2. Мобильное приложение отправляет запрос в smart-home-adapter с deviceId с передачей Access Token пользователя.
3. smart-home-adapter проверяет валидность токена.
4. smart-home-adapter по deviceId ищет в своей БД (smart-home-db) соответствующий externalDeviceId у партнёра.
5. smart-home-adapter проверяет, есть ли у пользователя право на это устройство.
6. Формирует запрос к API партнёра, добавляя externalDeviceId и команду и отправляет запрос
7. Партнёр Умного дома проверяет сертификат клиента (mTLS).
8. Партнёр Умного дома проверяет, что externalDeviceId принадлежит клиенту PropDevelopment.
9. Партнёр Умного дома отправляет команду на физическое устройство.
10.Партнёр Умного дома возвращает статус выполнения в smart-home-adapter.
11.smart-home-adapter логирует операцию и возвращает результат в мобильное приложение.
